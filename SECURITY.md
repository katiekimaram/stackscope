# Security

This is an early preview. Do not publish private diagnostic data, credentials, or exploit secrets in public issues. Contact the repository owner through an established private channel; a dedicated security reporting address is not configured yet.

Imported files, community contributions, and source evidence are untrusted. The renderer has no arbitrary filesystem or shell access. Privileged IPC validates the sender, paths, methods, and input sizes. The fixed native identity command is used only for account enrollment/login.

Community votes are opinions. Hosted uploads are explicit. Device/network limits are abuse friction, not proof of hardware or household identity. Stripe signatures and server-side status control hosted entitlements.

Before production, independently review parser limits, Electron IPC, the locked dependency graph, authentication/recovery, moderation, billing lifecycle, database isolation, rate limits behind the selected proxy, deployment, and release signing.
